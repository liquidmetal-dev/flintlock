# Website

This website is built using [Hugo](https://gohugo.io/) with the
[Hextra](https://imfing.github.io/hextra/) theme, which is pulled in as a Hugo
module (see `go.mod`). No Node.js or npm packages are needed.

### Installation

Run `mise install` from the repository root to get the pinned Hugo version.
Hugo modules also need `go` on your `PATH`.

### Local Development

```
$ hugo server
```

This starts a local development server at http://localhost:1313/ that reloads
on changes.

### Build

```
$ hugo --gc --minify --panicOnWarning
```

This generates the static site into the `public` directory. Broken internal
links fail the build.

### Content

- Pages live under `content/docs/`. Order them with `weight` in the front matter.
- Use GitHub-style alerts (`> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, ...) for
  callouts.
- Link to other pages with relative `.md` paths or site paths such as
  `/docs/guides/production`.
- `content/docs/grpc/` is generated by `make generate-proto` from
  `hack/proto-doc.md.tmpl`; don't edit it by hand.

### Deployment

The site is deployed by Netlify using `netlify.toml`.
